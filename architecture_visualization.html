Security Architecture & Encrypted Vault

Trust boundaries and AES-256-GCM encryption safeguarding portal passwords and session tokens.

Untrusted Public Boundary External Web
  • • Job Portals: Bot detection, Cloudflare captchas, session invalidation.
  • • LLM Cloud Endpoint: Third-party reasoning API via TLS 1.3.
Countermeasure: Gaussian pacing (8-25s), Playwright fingerprint spoofing, zero-retry immediate halt.
Local Host Trust Perimeter Candidate Machine
  • • AES-256-GCM Portal Vault: User IDs and passwords encrypted at rest in SQLite.
  • • File Secrets: Master key loaded from ${SECRETS_PATH} with 0600 permissions.
  • • Zerolog Sanitizer: Strips phone numbers, auth cookies, and bearer tokens before logging.
Countermeasure: Adheres strictly to go-secrets-file-mounted and go-logging-zerolog.

Data Retention & Backup Policy (NFR-4.5 / NFR-4.6)

  • • Application History: Retained indefinitely as permanent audit trail.
  • • Question Memory: Retained indefinitely to continuously build candidate Q&A corpus.
  • • Daily Online Backups: Uses SQLite VACUUM INTO after every 09:00 AM run; rolling 7 backups kept.
  • • Resume Files: Latest active in resumes/active/; replaced versions kept for 90 days in archive.
  • • Session Cookies: Purged automatically if inactive for > 7 days.

Deployment Architecture & Remote Access

Self-contained local hosting on candidate hardware, Tailscale zero-trust mobile tunneling, and platform distribution.

Single Binary Portability • Zero Cloud DB Dependency
1. Candidate Host Machine Local Service

Runs as a background service or terminal command on personal laptop or home home server.

  • • job-agent Go binary (embedded SPA)
  • • Chromium headless (Playwright)
  • • ~/.job-agent/data/jobs.db (SQLite)
  • • ~/.job-agent/secrets/ (0600 keys)
2. WireGuard Tunnel (Tailscale) Zero Trust

Provides private, end-to-end encrypted remote access from smartphone without public ports or dynamic DNS.

  • • Bind: SERVER_HOST=0.0.0.0
  • • Mobile: http://100.x.y.z:8080
  • • Zero port forwarding needed
  • • Mutual WireGuard authentication
3. External Cloud APIs Outbound TLS

Outbound connections only. Never accepts unsolicited inbound requests from public web.

  • • Portals (HTTPS / Stealth Playwright)
  • • LLM Cloud API (TLS 1.3 / JSON schema)
  • • Zero open public inbound ports

First-Run Bootstrap Lifecycle (NFR-5.3)

  1. Filesystem Setup: Auto-creates resumes/, backups/, and logs/ in ${DATA_PATH}.
  2. Permission Guardrail: Validates master_vault_key.txt is restricted to 0600; halts with safety error if insecure.
  3. Embedded Migrations: Executes SQL migrations 001 to 004 in an atomic transaction.
  4. Admin Creation: Detects zero users and opens setup wizard for initial candidate credentials.
  5. Browser Dependency: Verifies Chromium binary presence; informs user to run make install-browser if absent.
