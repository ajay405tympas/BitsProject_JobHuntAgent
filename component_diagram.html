1. Presentation & Ingress

Mobile-friendly web dashboard and API gateway. Designed with strict interface boundaries, allowing it to serve embedded assets or run as an independent edge gateway service.

React SPA • HTTP Gateway • SSE Streaming Broker
2. Autonomous Agent Services

Domain capabilities organized as isolated agent services: Crawler Agent, 70% Recency Matching Agent, and 3-Tier QA Reasoning Agent. Can run unified or deploy as discrete microservices/workers.

Crawler Agent • Matching Agent • QA Reasoning Agent
3. Local Storage & Vault

Single jobs.db SQLite file in WAL mode with a 1-writer / 4-reader connection pool. Backed up after every run via VACUUM INTO with a rolling 7-day retention.

WAL Journal • 0600 File Secrets • Indexed Queries
4. Zero-Trust Connectivity

The agent requires zero open inbound firewall ports. Remote mobile phone access is routed through an encrypted Tailscale WireGuard tunnel. All cloud calls use outbound TLS 1.3.

Tailscale Mesh • No Port Forwarding • Outbound Only
